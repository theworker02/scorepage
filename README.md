# scorepage

Score digests and page fingerprints for local integrity checks.

**Site:** https://theworker02.github.io/scorepage/

## Install / run

```bash
git clone https://github.com/theworker02/scorepage.git
cd scorepage
node src/cli.js
node --test
```
